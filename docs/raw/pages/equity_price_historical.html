股票历史K线 free

获取美股历史K线（OHLCV）数据

GET /api/v1/equity/price/historical

参数类型必填默认值说明示例
symbol string 否 - Symbol to get data for. Only a single symbol is supported. no RWA prefix is added. AAPL
symbols string 否 - Comma-delimited underlying symbols. -
start_time integer 否 - Start time of the data as a Unix timestamp in milliseconds. -
end_time integer 否 - End time of the data as a Unix timestamp in milliseconds. -

更新频率：-

请求示例

curl "https://agent.bitget.com/api/v1/equity/price/historical"

响应字段说明

字段类型说明
date string The date of the data.
open number The open price.
high number The high price.
low number The low price.
close number The close price.
volume number The trading volume.
vwap number Volume Weighted Average Price over the period.
