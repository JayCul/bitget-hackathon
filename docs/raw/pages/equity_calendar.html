美股

财报日历 free

获取美股财报发布日历

GET /api/v1/equity/calendar

参数类型必填默认值说明示例
symbol string 是 - Symbol to get data for. AAPL
fiscal_year integer 否 - Fiscal year, e.g. 2024. -
start_date string 否 - Start date of the data, in YYYY-MM-DD format. -
end_date string 否 - End date of the data, in YYYY-MM-DD format. -

更新频率：-

请求示例

curl "https://agent.bitget.com/api/v1/equity/calendar?symbol=AAPL"

响应字段说明

字段类型说明
symbol string Symbol to get data for.
period_ending string Period ending date of the report.
fiscal_year integer Fiscal year.
name string Name of the entity.
listed_country_code string 上市国家地区编码。
listed_country_name string 上市国家地区名称。
report_type_code string 报告类型编码。
report_type_name string 报告类型名称。
org_id string 机构 id。
perf_briefing_fore_dsclsr_date string 业绩简报预计披露日期。
perf_brief_dsclsr_date string 业绩简报披露日期。
perf_report_dsclsr_date string 业绩报告披露日期。
perf_report_fore_dsclsr_date string 业绩报告预计披露日期。
is_trading_time string 盘前/盘后。
