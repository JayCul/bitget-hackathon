新闻

新闻检索 free

按标签检索财经新闻

GET /api/v1/news/label_search

参数类型必填默认值说明示例
label integer 是 - News label type to search for. Accepts either the integer type code or the human-readable name: 1=Crypto, 2=Stocks, 6=Commodities & Forex, 7=Macro. crypto
language_id integer 否 0 Language filter. Accepts either the integer language code or a locale string (e.g. 'en', 'zh-CN', 'ja'). Defaults to 0 (English). -
start_time string 否 - Start of the time range. Accepts a datetime object, an ISO-8601 string, or a Unix timestamp (seconds or milliseconds). Converted to millisecond epoch before sending to the API. -
end_time string 否 - End of the time range. Accepts a datetime object, an ISO-8601 string, or a Unix timestamp (seconds or milliseconds). Converted to millisecond epoch before sending to the API. -
page integer 否 1 Page number for pagination (1-based). Defaults to 1. -
page_size integer 否 10 Number of news items per page. Defaults to 10. Maximum 1000. -

更新频率：-

请求示例

curl "https://agent.bitget.com/api/v1/news/label_search?label=crypto"

响应字段说明

字段类型说明
title string News article title.
content string Full HTML/text content of the news article.
labels string Human-readable label names associated with the article (e.g. ['Crypto', 'Stocks']).
language string Locale string of the article language (e.g. 'en', 'zh-CN').
published_at string Publication timestamp of the article.
date string Datetime (UTC). Same as the article publication time.
