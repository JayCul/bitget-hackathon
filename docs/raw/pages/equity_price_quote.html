美股

股票基本信息 / 实时报价 free

获取美股的实时报价与基本信息

GET /api/v1/equity/price/quote

参数类型必填默认值说明示例
symbol string 是 - Symbol to get data for. BTCUSDT

更新频率：-

请求示例

curl "https://agent.bitget.com/api/v1/equity/price/quote?symbol=BTCUSDT"

响应字段说明

字段类型说明
symbol string Symbol representing the entity requested in the data.
asset_type string Type of asset - i.e, stock, ETF, etc.
name string Name of the company or asset.
exchange string The name or symbol of the venue where the data is from.
bid number Price of the top bid order.
bid_size integer This represents the number of round lot orders at the given price. The normal round lot size is 100 shares. A size of 2 means there are 200 shares available at the given price.
bid_exchange string The specific trading venue where the purchase order was placed.
ask number Price of the top ask order.
ask_size integer This represents the number of round lot orders at the given price. The normal round lot size is 100 shares. A size of 2 means there are 200 shares available at the given price.
ask_exchange string The specific trading venue where the sale order was placed.
quote_conditions string Conditions or condition codes applicable to the quote.
quote_indicators string Indicators or indicator codes applicable to the participant quote related to the price bands for the issue, or the affect the quote has on the NBBO.
sales_conditions string Conditions or condition codes applicable to the sale.
sequence_number integer The sequence number represents the sequence in which message events happened. These are increasing and unique per ticker symbol, but will not always be sequential (e.g., 1, 2, 6, 9, 10, 11).
market_center string The ID of the UTP participant that originated the message.
participant_timestamp string Timestamp for when the quote was generated by the exchange.
trf_timestamp string Timestamp for when the TRF (Trade Reporting Facility) received the message.
sip_timestamp string Timestamp for when the SIP (Security Information Processor) received the message from the exchange.
last_price number Price of the last trade.
last_tick string Whether the last sale was an up or down tick.
last_size integer Size of the last trade.
last_timestamp string Date and Time when the last price was recorded.
open number The open price.
high number The high price.
low number The low price.
close number The close price.
volume integer The trading volume.
exchange_volume integer Volume of shares exchanged during the trading day on the specific exchange.
prev_close number The previous close price.
change number Change in price from previous close.
change_percent number Change in price as a normalized percentage.
year_high number The one year high (52W High).
year_low number The one year low (52W Low).
total_shares number Total shares outstanding (low-frequency, from the stock screener index).
float_shares number Float (freely tradable) shares outstanding (low-frequency, from the stock screener index).
total_market_cap number Total market cap = total_shares x last_price, computed in real time.
float_market_cap number Float market cap = float_shares x last_price, computed in real time.
pb number Price-to-book ratio = total_market_cap / latest reported shareholders' equity, computed in real time.
turnover_rate number Turnover rate (%) = volume / float_shares x 100, computed in real time.
amplitude number Intraday amplitude (%) = (high - low) / prev_close x 100, computed in real time.
